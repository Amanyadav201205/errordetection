ALGORITHM SUITE

Implemented Error Control Techniques

Deep mathematical modeling of Data Link Layer error detection and forward error correction mechanisms

1D

1D Parity Check

Even & Odd Schemes

Appends a single redundancy bit to ensure the total count of binary 1s is even or odd. Offers minimum bandwidth overhead for single-bit error detection at the receiver.

P = b_1 ⊕ b_2 ⊕ ... ⊕ b_n
Open in Simulator ➔
2D

2D Parity Check (Matrix)

Row & Column Intersection

Organizes binary stream into an M × N matrix grid. Calculates both horizontal row and vertical column parities. Intersecting parity discrepancies pinpoint exact bit coordinates for automatic correction!

Error at (Row_i, Col_j)
Open in Simulator ➔
HAM

Hamming Code (n, k)

Forward Error Correction

Inserts check bits at power-of-two bit positions (1, 2, 4, 8, ...). Evaluates syndrome bit equations at the receiver to calculate the exact corrupted bit index and flips it back automatically.

Syndrome S = (s_3 s_2 s_1)_2
Open in Simulator ➔
CHK

Internet Checksum

1's Complement Summation

Divides binary stream into k-bit blocks (4, 8, or 16 bits), computes 1's complement binary addition with wraparound end-around carry, and inverts the sum. Fundamental check used in IPv4, TCP, and UDP headers.

Checksum = ~Sum(W_1 + W_2 + ...)
Open in Simulator ➔
CRC

Cyclic Redundancy Check

Modulo-2 XOR Polynomial

Applies binary polynomial division over GF(2) with XOR operations. Detects all single-bit errors, double-bit errors, odd numbers of errors, and burst errors up to generator polynomial degree.

Frame = (Data × 2^r) + Remainder
Open in Simulator ➔
NS2

NS-2 Channel Simulator

Network Simulator 2 (WSL)

Simulates physical network duplex link between Node 0 (Transmitter) and Node 1 (Receiver) with an ErrorModel. Parses .tr event traces (+, -, d, r) and computes Packet Error Rate (PER).

Loss Ratio = Dropped / (Rx + Drop)
